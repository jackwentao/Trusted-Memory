# 写入保护范围

Phase 1 在自建测试台内使用虚构资料。调用方根据真实入口赋予来源，正文里的自称不改变来源。E 组先执行 SecurityMiddleware.inspect，只把 approved_text 送入提取、缓存与存储。BLOCK 没有可写正文。REVIEW 的净化文本供单独复核，不能参与事实检索。审计文件只含生成的编号、时间、来源、决定及固定原因码，写审计失败时调用中止。

目前文档和工具输入统一待确认。这能避免自动覆盖，但对无害外部更新同样有成本。测试必须包括正常纠正和引用讨论。规则识别若干中文与英文指令形式及常见格式的手机号、身份证、卡号、带前缀的密钥；其覆盖率与误拒率留给冻结的评测集测量。预处理前不应记录请求正文或向远端服务发送正文。真实入口的全链路检查属于 Phase 2。
