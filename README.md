# Trusted-Memory

基于开源 Mem0 的长期记忆评测项目，比较完整历史、原文检索、原版记忆、时间版本管理和写入保护。

<a id="architecture"></a>
## Architecture

A 向回答模型提供完整历史。B 用本地 BGE-M3 查找原始会话。C 使用 Mem0 2.2.1、DeepSeek 与同一款 BGE-M3。D 在 Mem0 外用 SQLite 管理事实版本，在 Qdrant 中查找指定时间有效的记录。只有现居地、当前公司、在读学校、主用手机号和当前职位可以替换旧值。购物、宠物、偏好、老家和事件分别保存。用户档案只从用户发言提取。助手建议单独保存，可供后续查询。E 在 D 的全部写入前增加来源审核、脱敏和指令过滤。

<a id="evaluation"></a>
## Evaluation

安装 uv，按 `.env.example` 在本地 `.env` 填好 CommandCode 密钥。首次运行需要联网下载公开对话和 BGE-M3 权重。从仓库根目录运行：

```sh
uv run --locked --env-file .env python scripts/run_eval.py --limit 60 --workers 16
```

已提交 Dev 和 Test 的场景清单。单独重建清单使用 `uv run --locked python scripts/build_eval_dataset.py`。以下是 同一批 Dev-60 的五组实测。B–E 最多检索 15 条，C 沿用 Mem0 原生抽取，D/E 分别记录双方发言。回答和评分均使用 DeepSeek V4.1 Flash（温度 0），公开题使用 LongMemEval oracle 会话，完整设置、分类结果和局限见 [评测报告](eval/REPORT.md)。
