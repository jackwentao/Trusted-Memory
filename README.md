# Trusted-Memory

基于开源 Mem0 的长期记忆评测项目，比较完整历史、原文检索、原版记忆、时间版本管理和写入保护。

<a id="architecture"></a>
## Architecture

A 向回答模型提供完整历史。B 用本地 BGE-M3 查找原始会话。C 使用 Mem0 2.2.1、DeepSeek 与同一款 BGE-M3。D 在 Mem0 外用 SQLite 管理事实版本，在 Qdrant 中查找指定时间有效的记录。住址等单值变化保留新旧版本，购物和兴趣等可并存的事实分别保存。属性名称由模型根据对话确定。E 在 D 的全部写入前增加来源审核、脱敏和指令过滤。

<a id="evaluation"></a>
## Evaluation

安装 uv，按 `.env.example` 在本地 `.env` 填好 CommandCode 密钥。首次运行需要联网下载公开对话和 BGE-M3 权重。从仓库根目录运行：

```sh
uv run --locked --env-file .env python scripts/run_eval.py --limit 60 --workers 16
```

已提交 Dev 和 Test 的场景清单。单独重建清单使用 `uv run --locked python scripts/build_eval_dataset.py`。以下是D/E 开放事实属性后的 Dev-60 五组实测，完整设置、分类结果和局限见 [评测报告](eval/REPORT.md)。
